# iTantra Pre-Rendered Emergency Audio Alerts (.wav)

This directory houses the offline pre-rendered 16kHz Mono 16-bit PCM .wav sound bytes for instant 0ms broadcast playback:

1. `flood_alert_hi.wav` - बाढ़ चेतावनी (Flood Warning)
2. `medical_sos_hi.wav` - आपातकालीन चिकित्सा सहायता (Medical SOS)
3. `fire_outbreak_hi.wav` - आग आपातकाल (Fire Outbreak)
4. `earthquake_hi.wav` - भूकंप चेतावनी (Earthquake Alert)
5. `evacuate_now_hi.wav` - तुरंत खाली करें (Evacuate Now)
6. `need_backup_hi.wav` - तत्काल मदद चाहिए (Need Backup)

When triggered, these alerts bypass neural STT and TTS inference pipelines completely for instant 0ms latency transmission over Bluetooth SPP and Wi-Fi Direct mesh.
